ESP32-P4 BadUSB — Web Flasher

Ports of QWavey's esp32-p4-hub-keylogger for the Spotpear ESP32-P4-MINI-B-M-EXT (P4 N32R32 + on-board C6). Flash both chips right from your browser — no esptool, no IDF.
Order matters. Flash the P4 first, then the C6. Don't skip the switch position or the boot-hold — the CH334 hub on the board multiplexes the USB port and the wrong combo will silently fail.

Step 1  —  Flash the P4

1
Set the U4 switch to FLASH / 0 (the position that routes the core Type-C to the P4's USB-Serial-JTAG). This is the P4 flashing position.
2
Hold BOOT on the P4, tap RESET (or plug the cable in while holding BOOT), then release BOOT. The P4 is now in the ROM boot loader — Windows / macOS enumerates it as a serial device (COMxx / /dev/tty.usbmodem*).
3
Click the button, pick the port that just appeared, and let it write. About 15 seconds.
chip family: ESP32-P4
4
When it says "Installation complete", tap RESET on the P4 (no BOOT this time). The status LED does 3 green blinks then dim green — that's the P4 online.

Step 2  —  Flash the C6

1
Move the U4 switch to position 1 — this routes the Type-C to the on-board ESP32-C6-MINI-1 for programming. The C6 is now the device your PC sees on the port.
2
Hold C6_BOOT on the M-EXT board, tap C6_RESET, release C6_BOOT. Another serial device shows up.
3
Flash. About 30 seconds (the C6 image is bigger — includes the 2 MB SPIFFS UI bundle with the full Hak5 language pack set).
chip family: ESP32-C6
4
Flip the U4 switch back to FLASH / 0 (P4 position) and reset. The P4 is what the target PC will see over USB (HID + MSC composite). The C6 sits on-board and serves the Wi-Fi AP.

Step 3  —  Connect

  1. Look for the Wi-Fi network P4-KeyLogger — password changeme123.
  2. Open http://192.168.4.1. That's the ported BadUSB UI.
  3. The old keylog dashboard is still around at http://192.168.4.1/klog, and the Keylog tab in the UI reads from the same live channel.
Requirements: Chromium browser (Chrome, Edge, Opera, Brave, Arc), a USB-C data cable, and a Spotpear ESP32-P4-MINI-B-M-EXT (N32R32 variant recommended so the 16 MB MSC partition fits). Web-flashing needs the tab to be served over HTTPS — GitHub Pages does that automatically.
